# From 20 to 22

## Requirements

- Angular 22: `@angular/core`, `common` and `platform-browser` `^22`.
- `@angular/router`, `@angular/cdk` and `@angular/material` (`^22`) are now declared peers: install them if they
  were only transitive before.

## Breaking changes

| Before | Now |
|--------|-----|
| `opened` fired on collapse and `closed` on expand. | `opened` fires on expand, `closed` on collapse. |
| `isSlidingInFromLeft` / `isSlidingInFromRight` were booleans. | They are read-only signals: call them. |
| Items without a route rendered as empty links. | They render as buttons, like parents and the back row. |
| Title items were links and could pop the stack. | Titles are plain text. |
| Disabled links kept their `href`. | They use `aria-disabled` and have no `href`. |
| The resize handle itself was the focus target. | The focusable separator is `hr.ngx-sidenav__resize-indicator`; the panel is a `<nav>`. |
| Escape always collapsed the panel. | Escape collapses only in backdrop (modal) mode. |
| `componentData` was ignored. | Each entry is set as a component input; other keys are skipped with a warning. |
| `initialWidth` overrode the width chosen by the user. | A persisted width wins (clamped); a first visit starts expanded. |
| `restoreStackHybrid()` replaced an existing stack. | It only fills an empty stack. |
| Route restore ignored the base href. | Routes are matched with `Location.path()`. |
| A route not in the menu reset the stack to the root. | The levels shown before, or saved by the previous visit, are kept; root items replace a stack restored from storage. |
| The stored stack held the menu items (`SerializableStackItem`). | It holds level keys (`{ "v": 2, "levels": [...] }`); a 20.x stack is migrated once. `restoreStackFromStorage(rootItems?)` takes the root menu. `SerializableStackItem` is deprecated. |

## New features

- `provideSidenav()` with `withManifest()` and `withSearchIndex()` (optionally in a Web Worker,
  `@fsegurai/ngx-sidenav/worker`).
- The `items` and `search` inputs of `<ngx-sidenav>`, and `<ngx-sidenav-search>`.
- Lazy levels (`loadChildren`), split manifests (`childrenSource`), stale-while-error sources and `retry`.
- `externalUrl`, `redirect`, `deprecated`, `disabled` and `tooltip` on menu items.
- Translatable labels (`SIDENAV_LABELS`, `provideSidenavLabels()`).
- Light and dark themes, and large-dataset performance (see the Performance guide).

## Steps

1. Update Angular to 22 and install the peers.
2. Swap `opened` and `closed` handlers back if you had compensated for the old behavior.
3. Replace reads of `isSlidingInFrom*` with signal calls.
4. Update custom styles or tests that targeted the old item, title or resize-handle elements.
5. Pass the root items to `restoreStackFromStorage()` if you call it yourself, and stop reading or writing
   `localStorage['ngx-sidenav-stack']` directly.
6. Optionally move a hand-written menu to `[items]` or a generated manifest.

The complete list is in the CHANGELOG.
