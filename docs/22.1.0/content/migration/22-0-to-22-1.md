# From 22.0 to 22.1

> **⚠️ Breaking markup changes in a minor release.** The library's major version follows Angular's, so removing
> Angular Material ships in `22.1.0`. A `^22.0.0` range picks it up: pin `~22.0.0` to stay on 22.0, or follow the
> steps below. Apps that never styled or tested the sidenav's internal markup usually only need step 1.

## Requirements

- Angular 22 and `@angular/cdk` `^22` (unchanged).
- `@angular/material` is **no longer a peer dependency**. Keep it only if your app uses it.

## What changed

| Before (22.0.0) | Now (22.1.0) |
|-----------------|--------------|
| `MatTooltip` on rows and the resize handle | `SidenavTooltip` (CDK overlay, `.ngx-sidenav-tooltip`), styled by `--ngx-sidenav-tooltip-*` on `:root` |
| `<mat-icon>` for the back arrow, chevron, toggle and external link | Inline `<svg>` with the same class names (`ngx-sidenav-menu__icon`, `ngx-sidenav__toggle-icon`, `ngx-sidenav-link__external-icon`) |
| `<mat-icon>` for `iconType: 'material'` items | `<span class="ngx-sidenav-menu__icon material-symbols-outlined">` |
| `menuIconCollapse` / `menuIconExpand` defaulted to `menu_open` / `menu` | Default `undefined` (built-in SVGs); a value still renders that Material Symbols ligature |
| Active row: `border-left-color-active` on the row border | An indicator (`::before`) drawn over the rail; same look with the default variables |
| Scrollbar thumb: `--ngx-sidenav-content-background-color[-hover]` | `--ngx-sidenav-scrollbar-thumb-color[-hover]`; the old names are deprecated fallbacks |

## Steps

1. Remove `@angular/material` from your dependencies if nothing else uses it. Material theme bridges written only for
   the sidenav tooltip or icons can go.
2. Update custom styles or tests that targeted `mat-icon`, `.mat-mdc-tooltip` or `MatTooltip`: use the
   [class hooks](../guides/customization.md#class-hooks), and query tooltips as `.ngx-sidenav-tooltip` in the
   overlay container.
3. Move tooltip styling to `:root`: the panel renders in the CDK overlay container, outside `<ngx-sidenav>`.

   ```css
   :root {
     --ngx-sidenav-tooltip-background-color: #313033;
     --ngx-sidenav-tooltip-text-color: #f4eff4;
   }
   ```

4. Load the Material Symbols font only if you use `iconType: 'material'` or ligature toggle icons. Otherwise, render
   item icons with your own set through an [`ngxSidenavItemIcon` template](../guides/customization.md#item-icons).
5. If you relied on the `menu` / `menu_open` toggle ligatures, set them explicitly
   (`menuIconExpand="menu" menuIconCollapse="menu_open"`) or replace them with
   [`expand` / `collapse` glyph templates](../guides/customization.md#glyphs).
6. Rename `--ngx-sidenav-content-background-color[-hover]` to `--ngx-sidenav-scrollbar-thumb-color[-hover]`.
7. If you adopt the new `mode="over"` / `mode="auto"`, note that the overlay host is `position: fixed`
   (`.ngx-sidenav--over`); see [Responsive Layout](../guides/responsive-layout.md). The default `mode="side"` keeps
   the previous layout.

## Customization in place of Material

| Need | Use |
|------|-----|
| Colors, sizes, typography, spacing | The 142 CSS variables ([Theming](../guides/theming.md); full list in the README) |
| Your own item icons | `<ng-template ngxSidenavItemIcon let-item>` |
| Your own back, chevron, external or toggle glyphs | `<ng-template ngxSidenavGlyph="…">` |
| Anything else | The stable BEM class hooks |

Everything else in 22.1.0 is additive; see [What's new in 22.1.0](../release-notes/whats-new.md).
